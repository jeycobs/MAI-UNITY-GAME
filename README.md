# Solar Tacking (Солнечный Парус)

Solar Tacking — это аркадный 3D-симулятор космического корабля с уникальной физической механикой управления на базе Universal Render Pipeline (URP) в Unity.

Вместо классического прямого управления (WASD), игрок использует физику «солнечного ветра», ловя потоки радиации огромным солнечным парусом для маневрирования в плотном астероидном лабиринте.

___
Описание игры

Маршевые двигатели исследовательского судна полностью отказали в самом опасном секторе галактики. Единственный способ добраться до точки выхода — развернуть экспериментальный солнечный парус. Через весь сектор в одном направлении дует мощный непрерывный поток космического ветра. Игрок должен вращать парус, ловить ветер под нужными углами (галсировать) и уклоняться от процедурно сгенерированных астероидов. Одно касание скалы — и корабль разлетится на куски.
 Ключевые механики (Gameplay)

    Управление потоком (Tacking / Галсирование): В игре нет кнопок газа или тормоза. Ветер всегда дует строго вперед. Двигая мышь, игрок вращает парус вокруг своей оси.

    Честная физика: Сила тяги рассчитывается через скалярное произведение (Vector3.Dot) между направлением ветра и углом поворота паруса. При угле в 90° корабль летит прямо, при повороте под углом 45° — ветер начинает "соскальзывать", толкая корабль по диагонали, позволяя огибать препятствия.

    Динамическое поле препятствий: Уровень представляет собой плотное поле статичных астероидов. Любое столкновение (Collision) приводит к мгновенному уничтожению корабля и перезапуску уровня.

    Зона финиша: Для победы необходимо пересечь невидимый триггер (Collider IsTrigger) в конце астероидного поля.

 Технические особенности (Under the Hood)

Проект демонстрирует уверенное использование продвинутых встроенных инструментов Unity:

    Custom Editor Tool (Генератор астероидов):

        Написан собственный инструмент расширения редактора Unity (EditorWindow).

        Позволяет геймдизайнеру в один клик генерировать поля астероидов (с настройкой радиуса, количества и размера префабов) через кастомную кнопку в верхнем меню Tools.

    Visual Effect Graph (VFX):

        Солнечный ветер реализован через современную систему частиц VFX Graph на базе GPU.

        Бесконечный поток частиц (AABox Spawn), задающий визуальное направление ветра.

    Cinemachine (Динамическая камера):

        Камера настроена через модуль CinemachineCamera с использованием Position Composer.

        Написан кастомный скрипт: угол обзора камеры (FOV) динамически расширяется в зависимости от физической скорости (Rigidbody.linearVelocity) корабля, создавая кинематографичный эффект ускорения.

    Оптимизация (Baked Lighting):

        Так как на сцене генерируются сотни астероидов отбрасывающих тени, используется смешанное освещение.

        Все сгенерированные астероиды помечаются как Static, а тени запекаются на текстуры (Lightmapping) для экономии ресурсов и обеспечения высокого FPS.

    UI & Game Loop:

        Реализован полноценный цикл: Стартовое меню -> Геймплей -> Победа/Поражение -> Рестарт (с использованием Time.timeScale и SceneManager).

        Адаптивный UI с использованием TextMeshPro и Canvas Scaler.

 Управление

    Мышь (Влево / Вправо) — Поворот солнечного паруса.

    Левый клик — Взаимодействие с UI (Старт / Рестарт).

Как запустить проект


    Откройте проект в Unity 2022.3 (или новее).

    Убедитесь, что в Package Manager установлены пакеты: Cinemachine, Visual Effect Graph, Universal RP.

    Откройте сцену SampleScene (или вашу главную сцену) в папке Scenes.

    Нажмите Play в редакторе Unity.
